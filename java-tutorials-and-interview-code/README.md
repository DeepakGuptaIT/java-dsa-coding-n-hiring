# Java Tutorials and Interview Code

Curated tutorials and ready-to-use code snippets for Java interviews and learning.

## Overview

This project contains well-documented tutorial code and best practices for Java programming. **Note**: This is for learning and tutorial purposes, not for practice problems.

## Content

- **Interview Preparation**: Common interview questions and solutions
- **Code Patterns**: Reusable code patterns and best practices
- **Tutorials**: Step-by-step guides on Java concepts
- **Best Practices**: Industry-standard approaches to common problems
- **Design Patterns**: Implementation examples of GoF patterns

## Project Details

- **Language**: Java 21
- **Build Tool**: Maven
- **Framework**: Spring Boot 3.3.0
- **GroupId**: com.firealgo
- **ArtifactId**: java-tutorials-and-interview-code
- **Purpose**: For Java tutorials and interview preparation only

src/

## Getting Started

### Prerequisites
- Java 21 or higher
- Maven 3.6+

### Build
```bash
mvn clean install
```

### Run Tests
```bash
mvn test
```

### Run Application
```bash
mvn spring-boot:run
```

## How to Use

1. Browse the organized packages
2. Read the documentation in each module
3. Study the code examples
4. Review the test cases for usage patterns
5. Reference the implementations in your own work
