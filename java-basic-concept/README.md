# Java Basic Concepts

Foundational Java programming concepts and fundamentals for beginners and review.

## Overview

This project covers essential Java programming concepts suitable for beginners and as a reference for experienced developers.

## Topics Covered

- **Core Syntax**: Variables, Data Types, Operators
- **Control Flow**: if/else, loops, switch statements
- **Object-Oriented Programming**: Classes, Objects, Inheritance, Polymorphism, Encapsulation, Abstraction
- **String Manipulation**: String operations, regex patterns
- **Collections Framework**: Arrays, ArrayList, HashMap, HashSet, etc.
- **File I/O**: File operations, Streams, NIO
- **Exception Handling**: try/catch/finally, custom exceptions
- **Java Basics**: Access modifiers, static, final keywords

## Project Details

- **Language**: Java 21
- **Build Tool**: Maven
- **Framework**: Spring Boot 3.3.0
- **GroupId**: com.firealgo
- **ArtifactId**: java-basic-concept

## How to Use This Project

- Start with core concepts and progress through object-oriented programming topics.
- Study each example and adapt it to your own practice problems.
- Use Maven from the module root to compile and run tests as needed.

## Learning Recommendations

- Begin with syntax and data types
- Progress to OOP concepts
- Practice with Collections
- Master exception handling
- Explore I/O operations
