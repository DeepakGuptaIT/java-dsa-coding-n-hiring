# Coding Problem Solving in Java

A comprehensive project for coding and problem solving practice from popular online platforms.

## Overview

This project contains solutions to coding challenges from platforms like:
- **LeetCode** - Algorithm and data structure problems
- **HackerRank** - Competitive programming challenges
- **HackerEarth** - Practice problems
- **GeeksforGeeks** - Data structure and algorithm problems

## Project Details

- **Language**: Java 21
- **Build Tool**: Maven
- **Framework**: Spring Boot 3.3.0
- **GroupId**: com.firealgo
- **ArtifactId**: coding-problem-solving-in-java

## How to Use This Project

- Explore solution packages by platform and problem category.
- Keep new implementations organized under `src/main/java`.
- Use Maven from the project root to compile and verify tests.
- Document the problem description and approach within each solution.

## Contributing

- Follow Java naming conventions
- Write comprehensive test cases
- Add comments for complex solutions
- Keep solutions well-organized by topic
