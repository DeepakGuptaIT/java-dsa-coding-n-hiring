# Java Data Structures & Algorithms (Legacy Project)

The master project for learning and exploring Java data structures and algorithms - maintained for legacy purposes.

## Overview

This is an archived/legacy project that served as the original foundation for Java data structures and algorithm learning. Consider using the newer projects in the parent directory for current work.

## Project Details

- **Language**: Java 21
- **Build Tool**: Maven
- **Framework**: Spring Boot 3.3.0
- **GroupId**: com.firealgo
- **ArtifactId**: java-ds-algo
- **Status**: Legacy/Archived

## Getting Started

### Prerequisites
- Java 21 or higher
- Maven 3.6+

### Build
```bash
mvn clean install
```

### Run Tests
```bash
mvn test
```

### Run Application
```bash
mvn spring-boot:run
```
