# Hiring Challenge Java

Solutions and code for Java-based hiring challenges from companies and recruitment platforms.

## Overview

This project contains implementations for hiring challenges and interview problems specifically designed to test technical skills in Java programming, data structures, and algorithms.

## Challenge Categories

- **Technical Interviews**: Company-specific interview problems
- **Coding Assessments**: Timed coding challenges
- **Case Studies**: Real-world problem solutions
- **Design Patterns**: Implementation of design patterns

## Project Details

- **Language**: Java 21
- **Build Tool**: Maven
- **Framework**: Spring Boot 3.3.0
- **GroupId**: com.firealgo
- **ArtifactId**: hiring-challenge-java

## How to Use This Project

- Review company-specific challenge packages to understand requirements and constraints.
- Use test cases to validate edge cases and performance behavior.
- Keep solutions modular and reusable for future interview practice.

## Documentation

See `docs/` folder for detailed documentation of specific hiring challenges organized by company and date.
