# Data Structures & Algorithms

A focused project for learning and implementing data structures and algorithms in Java.

## Overview

This project provides implementations and explanations of fundamental and advanced data structures and algorithms.

## Topics Covered

- **Data Structures**: Arrays, Linked Lists, Stacks, Queues, Trees, Graphs, Hash Tables
- **Algorithms**: Sorting, Searching, Dynamic Programming, Greedy, Divide and Conquer
- **Graph Algorithms**: BFS, DFS, Dijkstra, Floyd-Warshall, etc.
- **String Algorithms**: Pattern Matching, Text Processing

## Project Details

- **Language**: Java 21
- **Build Tool**: Maven
- **Framework**: Spring Boot 3.3.0 (Web)
- **GroupId**: com.firealgo
- **ArtifactId**: ds-and-algo
